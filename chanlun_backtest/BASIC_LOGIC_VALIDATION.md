# 缠论的基本逻辑，到底"对不对"？——三项独立验证

> `LOGIC_ANALYSIS.md` 验证的是"一二三类买卖点组合成交易信号后，胜率/收益率相对随机
> 基线如何"——这是一个混杂了"执行方式"（逢信号必反手）的**复合结论**。这次往回退
> 一步，把缠论最基础的两条理论断言从"交易信号"这层剥离出来，做**纯描述性的统计验证**：
>
> 1. 笔/中枢的构建过程本身有没有逻辑自相矛盾？（结构自洽性）
> 2. "背驰"这个判断转折点的核心机制，是否真的比"没有背驰"更能预测后续反转？（核心断言一）
> 3. "中枢=震荡消化，中枢之间=趋势"这个市场观，是否有真实的统计基础？（核心断言二）
>
> 用 `validate_basic_logic.py` 在 PEPE/ORDI/ZEC 三币种 × 1m/5m/30m 全年数据上完整跑了
> 一遍。**结论是喜忧参半的**：中枢结构的统计基础极其扎实（9/9全部显著，汇总p值小到
> 四舍五入为0），但背驰这个核心预测机制在标准操作化定义下**没有**显示出统计显著的
> 预测优势——这为"为什么买卖点整体胜率低于随机基线"提供了一个更底层的理论解释。

## 1. 验证一：结构自洽性——笔/中枢的构建有没有自相矛盾

最基础的检验：既然缠论声称"笔"必须严格交替方向（一笔向上、下一笔必然向下，不可能
连续两笔同向），且相邻两笔必须首尾相接（前一笔的终点分型 = 后一笔的起点分型），
那这套由 `rs_czsc` 增量构建、经过我们 `safety_margin` 冗余处理的"绝对确认笔序列"
是否真的在全年数据上无一例外满足这两条约束？

| 数据集 | 笔总数 | 方向未交替次数 | 端点未衔接次数 | 自洽 |
|---|---:|---:|---:|---|
| PEPEUSDT 1m | 13558 | 0 | 0 | ✅ |
| PEPEUSDT 5m | 4548 | 0 | 0 | ✅ |
| PEPEUSDT 30m | 1046 | 0 | 0 | ✅ |
| ORDIUSDT 1m | 37234 | 0 | 0 | ✅ |
| ORDIUSDT 5m | 8316 | 0 | 0 | ✅ |
| ORDIUSDT 30m | 702 | 0 | 0 | ✅ |
| ZECUSDT 1m | 37223 | 0 | 0 | ✅ |
| ZECUSDT 5m | 8033 | 0 | 0 | ✅ |
| ZECUSDT 30m | 1360 | 0 | 0 | ✅ |

**结论**：9个数据集、累计超过 11 万笔，**方向交替和端点衔接这两条最基础的结构公理
0 次违反**。这说明 `rs_czsc` 的笔构建算法，加上我们为消除"未来函数"而做的
`safety_margin` 冗余处理，在实现层面是完全自洽的——后面两项检验的结果不会受
"笔本身构建有 bug"这个混杂因素干扰。

## 2. 验证二：背驰的核心断言——它真的能预测反转吗

### 2.1 方法：把"背驰"从"买卖点"里剥离出来单独测

缠论一类买卖点的完整定义是"创新高/新低 **且** 背驰（价格力度、MACD同向面积都比
上一同向笔更弱）"。这里做一次干净的**事件研究**，把比较范围严格限定在"创新高/新低"
这个前提已经成立的笔集合内部，只对比"背驰"和"非背驰（创了新高/新低，但推动力度
没有变弱）"这两组笔端点之后的价格走势——这样能单独隔离出"力度变弱"这个额外条件，
到底有没有增量的预测价值（而不是笼统地把"创新高/新低"本身的效果也算进去）。

对每一笔端点，衡量"未来 10/30/100 根K线后，价格朝这一笔的反转方向运动了多少"
（下跌笔看后续是否上涨，上涨笔看后续是否下跌），比较两组的胜率（>0的比例）和均值，
并用 Mann-Whitney U 检验判断"背驰组"是否显著优于"非背驰组"。

### 2.2 结果：全部不显著，部分周期甚至方向相反

汇总全部 9 个数据集（背驰组 n=12471，非背驰组 n=39734）：

| 未来K线数 | 背驰组胜率 | 非背驰组胜率 | 收益 Mann-Whitney p值 | 胜率卡方 p值 |
|---|---:|---:|---:|---:|
| 10根 | 69.32% | 69.65% | 0.981 | 0.489 |
| 30根 | 63.01% | 63.12% | 0.873 | 0.833 |
| 100根 | 57.32% | 57.69% | 0.885 | 0.472 |

**三个时间尺度上，p 值全部远大于 0.05，没有一个达到统计显著**；更值得注意的是，
三个尺度上背驰组的胜率都**略低于**非背驰组（虽然差距很小、不显著），完全没有体现出
"背驰应该比非背驰更容易反转"这个理论预期的方向。分币种/周期拆开看，9个数据集里
同样没有一个达到传统 0.05 显著性水平（最接近的是 PEPEUSDT 30m 在100根K线尺度上
p=0.139，仍未达标）。

| 数据集 | 10根后背驰/非背驰胜率 | 30根后 | 100根后 |
|---|---|---|---|
| PEPE 1m | 63.69% / 66.84% | 66.43% / 66.73% | 60.32% / 61.52% |
| PEPE 5m | 70.20% / 68.02% | 62.55% / 65.12% | 56.47% / 58.07% |
| PEPE 30m | 79.44% / 70.08% | 62.62% / 62.73% | 58.88% / 54.74% |
| ORDI 1m | 70.79% / 70.81% | 63.69% / 63.32% | 56.65% / 58.07% |
| ORDI 5m | 69.37% / 68.77% | 60.56% / 61.40% | 51.40% / 56.33% |
| ORDI 30m | 68.42% / 63.52% | 61.84% / 58.20% | 56.58% / 58.51% |
| ZEC 1m | 69.33% / 70.11% | 62.04% / 62.53% | 58.81% / 57.04% |
| ZEC 5m | 70.49% / 69.13% | 62.88% / 60.85% | 55.39% / 55.04% |
| ZEC 30m | 63.69% / 68.16% | 55.41% / 60.47% | 53.85% / 53.53% |

（注：这里的"胜率"是"创新高/新低的笔之后价格朝反转方向运动"的比例，普遍
55%~70%，明显高于50%——这其实反映的是"创新高/新低的笔后续大概率至少有一波反向
波动"这个更基础的均值回归现象，与背驰与否无关，两组都同样享有这个基础概率。）

### 2.3 解读

这是本次验证里最反直觉、也最重要的发现：**"价格力度+MACD同向面积双双走弱"这个
标准的背驰操作化定义，在我们测试的全部9个数据集上，都没有显示出比"没有背驰"更强的
反转预测力**。这直接触及了缠论买卖点体系的理论根基——一类买卖点的正当性完全建立在
"背驰=行情将尽"这个假设上，二类、三类买卖点又是在一类买卖点基础上做结构性延伸，
如果这个最底层的机制本身在数据上站不住脚，那么 `LOGIC_ANALYSIS.md` 里发现的"买卖点
整体胜率显著低于随机基线"就不只是"执行层"（逢信号必反手、手续费侵蚀）的问题，
而是**理论核心机制本身在这套常见量化操作化下就没有可验证的增量预测价值**。

## 3. 验证三：中枢的核心断言——它真的是震荡消化吗

### 3.1 方法：Kaufman 效率比

缠论认为"中枢内部是震荡消化，中枢之间的移动才是趋势"。用 Kaufman 效率比
（`|首尾净价格变化| / 逐K线绝对价格变化之和`，取值 [0,1]，越接近1说明走势越"直"、
越接近0说明越"来回拉锯"）分别衡量"中枢内部区间"和"中枢之间（离开中枢后到下一个
新中枢形成之前的区间）"这两类区间，用 Mann-Whitney U 检验判断趋势段是否显著更"直"。

### 3.2 结果：极其显著，效应量很大，9/9 全部同向

汇总全部 9 个数据集（中枢内区间 n=13106，趋势段区间 n=683）：

| 区间类型 | 区间数 | 效率比均值 |
|---|---:|---:|
| 中枢内部 | 13106 | **0.1279** |
| 中枢之间（趋势段） | 683 | **0.2864** |

趋势段的效率比是中枢内部的 **2.24 倍**，Mann-Whitney U 检验 p 值小到四舍五入为
0.000000（样本量 13106 vs 683，效应极其显著）。分数据集看，9个数据集全部同向
（趋势段效率比 > 中枢内效率比），7个数据集样本量足够单独跑出 p<0.001 级别的显著性：

| 数据集 | 中枢内效率比均值 | 趋势段效率比均值 | 倍数 | 单独检验p值 |
|---|---:|---:|---:|---:|
| PEPE 1m | 0.0812 | 0.1965 | 2.42x | 0.0000 |
| PEPE 5m | 0.1034 | 0.2877 | 2.78x | 0.0000 |
| PEPE 30m | 0.1331 | 0.4786 | 3.60x | 样本仅3个,未单独检验 |
| ORDI 1m | 0.1331 | 0.3104 | 2.33x | 0.0000 |
| ORDI 5m | 0.1375 | 0.3481 | 2.53x | 0.0000 |
| ORDI 30m | 0.1759 | 0.5881 | 3.34x | 样本仅3个,未单独检验 |
| ZEC 1m | 0.1338 | 0.2780 | 2.08x | 0.0000 |
| ZEC 5m | 0.1367 | 0.2871 | 2.10x | 0.0000 |
| ZEC 30m | 0.1586 | 0.3398 | 2.14x | 0.0840（n=8，接近但未达0.05） |

**结论**：无论哪个币种、哪个周期，"中枢内部"这个几何结构定义出来的区间，效率比
都稳定在趋势段的 1/2 到 1/3，且这个差异极其显著、9/9 全部方向一致——**这是本次
全部验证中最经得起检验、效应量最大、最没有例外的一条结论**：缠论用"连续三笔价格
区间重叠"这个纯几何规则去识别"震荡消化"区间，确实精准地捕捉到了真实存在的、
可用效率比量化的市场结构特征，这是缠论对市场结构的描述**里最站得住脚的部分**。

## 4. 总结：缠论的基本逻辑，哪些经得起检验，哪些经不起

| 断言 | 验证方式 | 结论 |
|---|---|---|
| 笔的构建过程本身逻辑自洽（方向交替、端点衔接） | 结构一致性检查，9个数据集、11万+笔 | ✅ **完全成立**，0次违反 |
| 中枢=震荡消化，中枢之间=趋势 | Kaufman效率比对比，13106 vs 683个区间 | ✅ **强力成立**，效应量2.24倍，p≈0 |
| 背驰（力度+MACD走弱）比非背驰更能预测反转 | 事件研究法，12471 vs 39734个笔端点 | ❌ **不成立**，9/9数据集均未达到统计显著 |

这三条结论放在一起，讲出了一个比"买卖点整体胜率低于随机基线"更精确的故事：

- **缠论对市场"结构"的划分是有真实统计基础的**——"笔"这个基本单位内部逻辑自洽，
  "中枢"这个核心创新精准捕捉到了真实存在的"震荡 vs 趋势"两种状态的区别。这部分
  可以认为是缠论**对市场行为的客观描述**，经得起独立于任何交易规则的统计检验。
- **但缠论用来"预测转折点"的核心机制（背驰）没有通过检验**——至少在"价格力度
  百分比 + MACD同向面积"这个业界最常见的操作化定义下，背驰笔和非背驰笔之后的
  价格走势在统计上无法区分。结合 `LOGIC_ANALYSIS.md` 里"买卖点胜率显著低于随机
  基线，收益率靠少数极端信号的赔率不对称"这个发现，现在有了一个更底层的解释：
  **不是执行方式（逢信号必反手、手续费）在拖后腿，而是"背驰⇒反转"这个理论前提
  本身，在我们能想到的最常见量化方式下，就没有表现出可验证的增量预测力**。
- 换句话说：**缠论"看懂了市场在做什么"（结构划分），但"背驰"这个具体机制未必
  真的"能提前判断市场接下来要做什么"**——这两者是缠论理论体系里两个独立的主张，
  本次验证第一次把它们分开检验，得到了截然不同的结论。

## 5. 方法论的局限性

1. **背驰的操作化定义不是唯一的**：这里用的是本项目 `chanlun_engine.py` 里"价格
   百分比力度 + MACD同向面积"这一种最常见的量化方式，缠论原著和各家实现对"力度"
   还有其他量化思路（如成交量、笔的斜率、多重时间尺度MACD背驰等），本次验证的
   "不成立"结论**只针对这一种具体操作化**，不能排除换一种"力度"定义后结果不同的
   可能性——但这恰恰也说明"背驰"这个概念在缠论原著里本身就存在**操作化歧义**，
   这也是一个值得记录的"逻辑漏洞"（理论概念不够形式化、不同实现可能得到不同结论）。
2. **趋势段样本量偏小**：由于中枢构建算法在实践中会"贪婪地"把新出现的重叠笔持续
   并入现有中枢延伸，真正"完全游离在任何中枢之外、连续多笔都没能形成新中枢"的
   纯趋势段数量远少于中枢本身（683 vs 13106，约 1:19），30分钟周期上单个数据集
   经常只有 3~8 个有效趋势段，样本量偏小，好在9个数据集合并后总量（683）已经足够
   支撑一个具有统计意义的整体结论，且9/9方向完全一致，稳健性较好。
3. **事件研究的"后续价格朝反转方向运动"是一个宽松的度量**：只看"是否运动、运动
   多少"，没有像 `LOGIC_ANALYSIS.md` 里的完整回测那样考虑手续费、仓位管理、连续
   反手的复合效应——这是特意为之的简化，目的就是**排除执行层因素、只看理论机制
   本身**，因此这里的"不显著"结论和 `LOGIC_ANALYSIS.md` 里"买卖点胜率显著低于
   随机基线"的结论是从两个不同角度得出的，但方向是一致的、互相印证的。
