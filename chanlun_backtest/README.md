# 阿娇版缠论 —— 数字货币真实胜率回测

本目录用**严格因果式（无未来函数）**的方式，实现了"阿娇版缠论"（即缠中说禅《教你炒股票》
108课体系）中最核心的可执行规则——笔、中枢、背驰、三类买卖点，并在**PEPEUSDT** 与
**ORDIUSDT**（两个高波动、但波动特征不同的币种）过去 **1 整年**（2025-06-01 ～ 2026-05-31）
的 **1分钟 / 5分钟 / 30分钟** K线上做了真实回测，统计真实胜率、盈亏比与收益曲线，并做了
单周期 vs 多级别联立、以及两个币种之间的对比。**当前版本不含任何止损/仓位管理**，纯粹按
缠论买卖点信号机械反手交易。

- PEPEUSDT 详细结论见 [`RESULTS.md`](./RESULTS.md)
- **PEPEUSDT vs ORDIUSDT 双币种对比**见 [`COMPARISON.md`](./COMPARISON.md)

## 目录结构

```
chanlun_backtest/
├── download_data.py             # 从 Binance 官方公开历史数据集下载 K 线（免 API Key）
├── chanlun_engine.py             # 缠论核心：笔（调用 rs_czsc）+ 中枢/背驰/买卖点/多级别联立（自实现，因果式）
├── backtest.py                    # 信号 -> 交易撮合 + 绩效统计（胜率/盈亏比/回撤等）
├── run_backtest.py                # 单周期回测（1m/5m/30m 各自独立）
├── run_backtest_multilevel.py     # 多级别联立回测（30m定方向→5m，5m定方向→1m）
├── data/                          # 下载的历史K线（parquet，未提交到 git，需要自行下载）
└── results/                        # 回测结果（交易明细 csv + 汇总 json，PEPEUSDT/ORDIUSDT 均有）
```

## 复现方法

```bash
pip install czsc pandas numpy pyarrow requests

# 1. 下载数据（可换任意币种/区间，脚本对 symbol 完全通用）
python download_data.py PEPEUSDT 2025-06 2026-05
python download_data.py ORDIUSDT 2025-06 2026-05

# 2a. 跑三个周期各自独立的回测（默认手续费单边 0.1%，即双边 0.2%）
python run_backtest.py --symbol PEPEUSDT --freqs 1m 5m 30m --fee 0.001
python run_backtest.py --symbol ORDIUSDT --freqs 1m 5m 30m --fee 0.001

# 2b. 跑多级别联立回测（30分钟定方向->5分钟找买卖点；5分钟定方向->1分钟找买卖点）
python run_backtest_multilevel.py --symbol PEPEUSDT --fee 0.001
python run_backtest_multilevel.py --symbol ORDIUSDT --fee 0.001
```

## 为什么选择 PEPEUSDT

用户要求"找一个不太稳定的数字货币"。PEPEUSDT 是市值较大、但价格波动剧烈的 meme 币：

- 测试区间内日收益率标准差 **5.3%**，年化波动率约 **101%**
- 单日最大涨幅 **+27.8%**，单日最大跌幅 **-27.5%**
- 区间最高价/最低价比值达 **5.29 倍**
- 买入并持有整年的收益率为 **-70.6%**（区间内经历了完整的大涨大跌周期）

## 第二个对比标的：ORDIUSDT

为了检验结论是否只是 PEPE 这一个币种的偶然结果，额外挑选了年化波动率更高（约198%，接近
PEPE 的两倍）、且波动"方式"明显不同（PEPE 持续阴跌，ORDI 中途出现过单周 +272% 的极端拉升）
的 **ORDIUSDT** 做同样口径的完整回测（同一区间、同样三个周期、同样的单/多级别联立规则、
同样不含任何仓位管理）。完整对比结论见 [`COMPARISON.md`](./COMPARISON.md)，核心发现：

1. "周期越长、胜率越高、回撤越小"在两个币种上都成立；
2. 多级别联立能稳定提升胜率，但**收益改善幅度强依赖标的的行情结构**，对 PEPE 是"扭亏为盈"，
   对 ORDI 更多是"减少亏损"；
3. **ORDI 因为波动中夹杂剧烈单边脉冲（一次短期内价格上涨 272%），暴露出"无止损裸空"策略
   在这类标的上的毁灭性风险**——单笔交易亏损可以超过 100%（即理论上的"倒欠"仓位），这个现象
   在 PEPE 测试中完全没有出现，只有通过跨币种对比才能发现。

## 无未来函数的关键实现细节

1. **笔的构建**完全交给 `czsc`（`rs_czsc` Rust 内核），这是一个逐根K线增量更新
   （`c.update(bar)`）的流式算法，天然因果。
2. **已发现并修复的未来函数陷阱**：`bi_list` 的**最后 1 个元素是"延伸中"的临时笔**，
   会随着新K线到来被原地修改甚至撤销（回退）。若直接用它判断买卖点，等于提前用到了
   "未来才会最终确定"的信息。修复分两层：
   - **安全冗余**：只使用 `bi_list[:-2]`（丢弃最新 2 笔）作为"绝对确认、不会再变"的
     笔序列，用它构建中枢、判断背驰、生成买卖点；
   - **运行时自证（而非一次性抽样测试）**：`ChanEngine.run(verify=True)`（默认开启）
     在**每一次实际回测运行、覆盖全部K线**时，持续比对相邻两次轮询中同一下标笔的
     指纹（起止时间+价格+方向），一旦发现 `bi_list[:-2]` 假设被打破就立刻抛出
     `RuntimeError` 并报告需要的最小冗余，而不是静默产出被未来信息污染的结果。
     `run_backtest.py` 在捕获到该异常时会自动加大冗余重跑。
   - **验证结果**：1分钟/5分钟/30分钟三个周期的**全年全部K线**均已完整跑过自证，
     `max_retraction_observed = 0`（即在验证覆盖的全部轮询点上从未观察到任何回退），
     `safety_margin=2` 的假设被完整证实，详见 `RESULTS.md`"运行时自证结果"一节。
3. **交易执行价 = 信号被程序发现那一刻所在K线的下一根K线开盘价**，而不是信号对应笔端点历史时刻
   的下一根K线——避免"程序批量轮询才发现信号，但拿信号发生时刻的价格成交"这种隐蔽的未来函数。
4. 中枢、背驰、三类买卖点的具体规则定义见 `chanlun_engine.py` 顶部注释与 `RESULTS.md`。

## 已知局限（务必阅读）

缠论本身在业界公认**依赖交易者主观判断**，不同人对"背驰""三买三卖"的具体量化方式存在争议
（这也是为什么会有"阿娇版"这样的民间注解版本帮助初学者理解）。本回测采用的是一套自洽、
在代码中完全公开、可复现的量化规则，但**不代表"缠论"或"阿娇版缠论"唯一正确的算法化实现**。
更换规则细节（例如背驰的判定阈值、中枢构建方式、止损止盈规则）会显著改变回测结果。

**当前版本完全没有止损/仓位管理**（按用户要求暂缓加入），这不是一个可以忽略的细节：
ORDIUSDT 的回测中已经真实出现了单笔亏损超过 100% 的"裸空爆仓"交易（详见
[`COMPARISON.md`](./COMPARISON.md) 第4节），说明在真实波动更剧烈的标的上，机械反手而不设
止损的做法有理论上无限的下行风险，本回测的收益率/回撤数字**不能**直接当作可实盘复现的
资金曲线，仅用于比较不同周期/标的/联立规则之间买卖点信号本身的方向判断力。
