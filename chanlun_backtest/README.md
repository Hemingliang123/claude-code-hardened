# 阿娇版缠论 —— 数字货币真实胜率回测

本目录用**严格因果式（无未来函数）**的方式，实现了"阿娇版缠论"（即缠中说禅《教你炒股票》
108课体系）中最核心的可执行规则——笔、中枢、背驰、三类买卖点，并在**PEPE/USDT**
（高波动 meme 币）过去 **1 整年**（2025-06-01 ～ 2026-05-31）的 **1分钟 / 5分钟 / 30分钟**
K线上做了真实回测，统计真实胜率、盈亏比与收益曲线。

详细结论见 [`RESULTS.md`](./RESULTS.md)。

## 目录结构

```
chanlun_backtest/
├── download_data.py    # 从 Binance 官方公开历史数据集下载 K 线（免 API Key）
├── chanlun_engine.py    # 缠论核心：笔（调用 rs_czsc）+ 中枢/背驰/买卖点（自实现，因果式）
├── backtest.py           # 信号 -> 交易撮合 + 绩效统计（胜率/盈亏比/回撤等）
├── run_backtest.py       # 一键运行三个周期的回测并输出结果
├── data/                 # 下载的历史K线（parquet，未提交到 git，需要自行下载）
└── results/               # 回测结果（交易明细 csv + 汇总 json）
```

## 复现方法

```bash
pip install czsc pandas numpy pyarrow requests

# 1. 下载数据（默认 PEPEUSDT，2025-06 ~ 2026-05，可换其他币种/区间）
python download_data.py PEPEUSDT 2025-06 2026-05

# 2. 跑三个周期的回测（默认手续费单边 0.1%，即双边 0.2%）
python run_backtest.py --symbol PEPEUSDT --freqs 1m 5m 30m --fee 0.001
```

## 为什么选择 PEPEUSDT

用户要求"找一个不太稳定的数字货币"。PEPEUSDT 是市值较大、但价格波动剧烈的 meme 币：

- 测试区间内日收益率标准差 **5.3%**，年化波动率约 **101%**
- 单日最大涨幅 **+27.8%**，单日最大跌幅 **-27.5%**
- 区间最高价/最低价比值达 **5.29 倍**
- 买入并持有整年的收益率为 **-70.6%**（区间内经历了完整的大涨大跌周期）

## 无未来函数的关键实现细节

1. **笔的构建**完全交给 `czsc`（`rs_czsc` Rust 内核），这是一个逐根K线增量更新
   （`c.update(bar)`）的流式算法，天然因果。
2. 实测发现 `bi_list` 的**最后 1 个元素是"延伸中"的临时笔**，会随着新K线到来被原地修改甚至撤销
   （实测最大回退深度为 1 笔）。因此本回测**只使用 `bi_list[:-2]`**（留 1 笔安全冗余）作为
   "绝对确认、不会再变"的笔序列，用它构建中枢、判断背驰、生成买卖点。
3. **交易执行价 = 信号被程序发现那一刻所在K线的下一根K线开盘价**，而不是信号对应笔端点历史时刻
   的下一根K线——避免"程序批量轮询才发现信号，但拿信号发生时刻的价格成交"这种隐蔽的未来函数。
4. 中枢、背驰、三类买卖点的具体规则定义见 `chanlun_engine.py` 顶部注释与 `RESULTS.md`。

## 已知局限（务必阅读）

缠论本身在业界公认**依赖交易者主观判断**，不同人对"背驰""三买三卖"的具体量化方式存在争议
（这也是为什么会有"阿娇版"这样的民间注解版本帮助初学者理解）。本回测采用的是一套自洽、
在代码中完全公开、可复现的量化规则，但**不代表"缠论"或"阿娇版缠论"唯一正确的算法化实现**。
更换规则细节（例如背驰的判定阈值、中枢构建方式、止损止盈规则）会显著改变回测结果。
